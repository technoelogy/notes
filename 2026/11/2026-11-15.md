# 2026-11-15

**Build:** ClearRx (voice-first prescription capture)
**Today:** Shipped P1. The live path works end to end on my machine: dictation to structured Rx to a legible pad.

## What I did
- Built a realistic doctor's prescription pad for the demo. The Indian conventions that make a doctor trust it: the Rx symbol, the 1-0-1 dosing grid, Tab/Cap prefixes, drug names in capitals, registration number, signature block.
- Scaffolded the P1 app: Next.js PWA, a voice capture hook, the structuring call, the review pad. Ran it locally.
- Wired live Claude structuring. Typed a prescription, got back a correct structured Rx rendered on the pad. Nothing hardcoded.

## What I learned
- The one that will stick: do not trust the model to produce your whole data structure. My first live call failed validation because the model guessed the JSON shape. The fix was to let the model return only the clinical content it actually heard, and have my server build the full record and own the safety fields. The "no invented dose" flag is now set by my code, not by the model. More reliable, and safer.
- Capturing structured data at the source is the whole game. The voice becomes JSON once, and the pad, the print, the WhatsApp image and a future health-record export are all just views of that one record.
- Local setup ate real time: node version, a stuck terminal, a zip that would not unzip. Worth a one-page setup checklist so the next build does not repeat it.

## Guardrail, proven in code
- Fed it a deliberately messy dictation with no clear dose. The record left the dose blank instead of inventing one. That is the rule that matters for anything touching a prescription, and it holds in the validator, not just the prompt.
